# Quick2 / 対象環境確認チェックリスト

## 現在の状態

**実環境確認: 未実施**
このリポジトリの開発・自動テストから実環境への接続は行っていません。以下は実施時に担当者が記録する空のチェックリストです。秘密、実URL、個人情報、障害情報はpublicリポジトリやPRへ記載しません。

## 接続前

- [ ] 管理者からRedmineベースバージョン、独自改修、公開REST API仕様を入手した
- [ ] REST APIが有効であり、`/users/current.json` と `/issues.json` が公開対象である
- [ ] 読み取り専用の専用ユーザー、ロール、利用権限、APIキーの保管/失効手順を承認した
- [ ] 対象プロジェクト範囲とプロジェクトID/識別子、閲覧可能範囲を承認した
- [ ] 子プロジェクトを除外/包含する際の対象環境のパラメータ挙動をテスト環境で確認した
- [ ] 全ステータスとトラッカーIDのフィルター挙動を確認した
- [ ] 社内CAチェーンと証明書名検証、TLS検査、proxy、`NO_PROXY` を情報システム部門と確認した
- [ ] 接続先URLのサブパスと、リダイレクトなしで到達する正規URLを確認した
- [ ] リポジトリ外の承認済み保存先、アクセス権、暗号化、保管期限、廃棄方法を確認した

## テスト環境での照合

- [ ] `check` のID/loginがログインユーザーと一致し、メールや全応答を表示しない
- [ ] 0件、小件数、複数ページで、画面のフィルター条件とAPI抽出条件が一致する
- [ ] 画面とCSV/JSONの件数、およびID、件名、project/tracker/status/担当者、日時を標本照合した
- [ ] 完了チケットが既定出力に含まれることを確認した
- [ ] 子プロジェクトが既定で除外され、明示時だけ含まれることを画面と照合した
- [ ] 権限のないプロジェクト/項目が漏えいせず、403/404の対象環境での使い分けを確認した
- [ ] 担当者未設定、日本語、改行、引用符、数式開始文字をExcelとJSONで確認した
- [ ] ページサイズ上限、最大想定件数、応答時間を測定し、安全なtimeout/上限を決めた
- [ ] 取得中更新では完全スナップショットにならない制約を業務所有者が受容した

## カスタム項目

- [ ] 管理者から必要なカスタム項目のID、名称、形式、複数値、必須/機密区分を入手した
- [ ] APIでの型（文字列、数値、日付、配列等）と権限別の可視性をダミーデータで確認した
- [ ] 出力の業務必要性と最小化を承認した（PR-1はカスタム項目を出力しない）

## 本番前承認

- [ ] テスト環境の記録をレビューし、未確認事項と差異を解消した
- [ ] 実行者、日時、対象、出力先、削除期限、インシデント連絡先を承認した
- [ ] APIキーや実データをコマンド履歴、ログ、リポジトリ、PRへ残さない手順を再確認した
